Firmware update

Release firmware: none on this page (choose a file below)

For USBGPIB-STM32 and LANGPIB-WCH. Plug the adapter in, click Update firmware and pick it in the list: the page finds which adapter it is, restarts it into its updater and writes the matching firmware.

The adapter isn't in the list

An adapter only starts USB once it has found a GPIB instrument. Without one, unplug it, hold SW1 while plugging it back in (LANGPIB-WCH: D1 double-blinks; USBGPIB-STM32: the LED stops blinking) and click Update firmware again. In the list the updater shows as "LAN GPIB adapter DFU" (LANGPIB-WCH) or "DAPBoot DFU Bootloader" (USBGPIB-STM32). Linux needs a udev rule giving your user access to 1209:0001 and 1209:db42. Use Chrome or Edge on a desktop computer.
